# Spec Delta

## ADDED Requirements

### Requirement: Unified structure hover outline

When the Structure Selection tool hovers a structure in molecules mode, the system SHALL highlight the structure with one visually continuous hover outline.

#### Scenario: Hovering a structure with Structure Selection

- **WHEN** the user hovers over a structure in molecules mode with the Structure Selection tool
- **THEN** the whole structure is highlighted as a single smooth united outline
