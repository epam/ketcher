# Ketcher demo

A minimal [Vite](https://vite.dev) app that consumes the published `ketcher-core`, `ketcher-react`, and `ketcher-standalone` packages.

## Scripts

Run them from `demo/`. `npm run build:demo` at the repo root builds the packages first.

- `npm start` starts the Vite dev server.
- `npm run build` writes the production build to `build/`. `PUBLIC_URL` sets the base path.
- `npm run serve` serves `build/` locally.
- `npm run test:types` type-checks the app.

Build details: [.memory-bank/build.md](../.memory-bank/build.md).
